# Network Configurator in C++ (ESP8266 Captive Portal)

Цей проєкт призначений для мікроконтролера **Wemos D1 mini (ESP8266)**. Він реалізує автономну точку доступу (Access Point) із функцією **Captive Portal** (примусового перенаправлення на вебсторінку конфігурації) за допомогою вбудованих бібліотек `DNSServer` та `ESP8266WebServer`.

---

## 🚀 Можливості проєкту

* **Створення точки доступу**: Плата роздає власний Wi-Fi із назвою `My_WiFi`.
* **DNS-перехоплення (Captive Portal)**: Будь-який запит користувача в браузері автоматично перенаправляється на внутрішню IP-адресу пристрою (`192.168.0.110`).
* **Локальний вебсервер**: Віддає базову сторінку з привітанням (у майбутньому розширюється під форму введення даних для підключення до домашнього роутера).

---

## 🛠 Апаратне та програмне забезпечення

* **Мікроконтролер**: Wemos D1 mini (ESP8266)
* **Середовище розробки**: VS Code + PlatformIO
* **Фреймворк**: Arduino

### Залежності (`platformio.ini`)
Проєкт використовує виключно стандартні бібліотеки ядра ESP8266:
* `ESP8266WiFi`
* `DNSServer`
* `ESP8266WebServer`
